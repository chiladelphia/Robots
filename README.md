# Robots

484 Team Robotics Club. Go!

## Website prototype

This repository contains a replacement-site prototype for Haverford High School FRC Team 484.

### Status

- Prototype only; the existing Team 484 website remains official until a transition is approved.
- Last reviewed September 27, 2026.
- Dates, fees, forms, contacts, and calendar information must be confirmed by team leadership before public launch.
- Publishing this repository does not change `team484.org` or its DNS.

### Site files

- `index.html` — public page structure and content
- `styles.css` — responsive visual design
- `.nojekyll` — serves the static files without Jekyll processing

### Before replacing the current site

1. Confirm current-season dates, fees, contacts, and forms.
2. Choose the calendar source of record.
3. Test form submissions and external links.
4. Assign content owners and review dates.
5. Obtain domain and DNS control.
6. Complete accessibility and link checks.
7. Plan redirects for useful historical URLs.
